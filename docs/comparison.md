## プロトタイプで実際に露わになった弱点

3案とも「触ってみたら同じ穴が空いていた」点が興味深い。**どれも、考えずに総当たりしたほうが速い。**

| | 総当たりの中身 | 塞ぐのに必要な作業 |
| --- | --- | --- |
| あと1手 | 合法な方向が2〜4つしかなく、全部試せば必ず解ける | 挑戦回数の記録・表示（小） |
| 未来予測 | 1/3〜1/5 を勘で選べば、たまに当たる | 補助情報（DPS表示）や2択化（中） |
| 見えない迷路 | 覚えずに歩き回り、壁ドンで地形を割り出す | 壁ドンを含む単一スコア（小） |

**あと1手** と **見えない迷路** は、それぞれ「回数の表示」「スコア化」という数十行の作業で塞げる。
**未来予測** は、勘ゲーム化の原因が「暗算が重い」という設計そのものにあるため、塞ぐには設計変更が要る。ここが3案の実質的な難易度差になっている。

## コンテンツ供給という観点

1日で作り切れるかとは別に、**遊べる時間の長さを何が決めるか**が3案で大きく違う。

| | 遊べる量を決めるもの | 供給コスト |
| --- | --- | --- |
| あと1手 | 手作りした問題数 | **高い**（解の一意性の検証も要る。ソルバーを書くまで詰まる） |
| 未来予測 | 編成の数 | **低い**（ランダム生成 数十行で無限） |
| 見えない迷路 | 迷路の数 | **最も低い**（生成器が本体。既に無限） |

「あと1手」だけ、ゲーム本体が完成した後にもうひと山ある。

## 結論（4つの観点で選ぶ）

### 最も安全な案 → **見えない迷路**

実装量が3案で最小、状態遷移が3つしかなく、破綻する要素がほぼない。プロトタイプ時点で既にゲームとして成立していた。1日で確実に「完成した」と言えるものが残る。
唯一の懸念は、完成させやすさと引き換えに独自性が最も低いこと。

### 最も面白くなる可能性が高い案 → **未来予測**

「並び順を読む」という思考が、実際に触って初めて立ち上がってきた。上限が見えていないのはこの案だけで、スキル・編成・体数といった伸ばす方向が具体的にいくつもある。
ただし現時点では **勘ゲーム寄り** で、面白さの芯が確定していない。当日に設計を詰め直す時間を見込む必要がある。ハイリスク・ハイリターン。

（なお「あと1手」も、パズルとしての気持ちよさの上限は高い。ただし伸びしろが**問題を作る能力**に完全に依存するので、1日という枠では実力を出しきれない。）

### 最もハッカソン映えする案 → **未来予測**

会場全員に「誰が勝つと思う？」と予想させてから STARTを押す、という見せ方ができるのはこの案だけ。HPバーが減り、ダメージ数字が飛び、💀 が並ぶ画面は、後ろの席から見ても何が起きているか分かる。
デモ映えは3案で頭ひとつ抜けている。

### 最も公開後に伸ばしやすい案 → **見えない迷路**

Daily Challenge / seed / URL共有 / スコア共有 が、追加設計なしで噛み合う。プロトタイプの seed 表示だけで、その筋が通ることは確認できた。
公開して人に配ることを重視するなら、この案が最短距離。

## 判断が分かれるポイント

最終決定の前に、これだけ決めれば選べる。

1. **1日の終わりに何が残っていてほしいか。**
   「完成したものを確実に残す」なら 見えない迷路。「未完成でも面白いものを掴みにいく」なら 未来予測。
2. **当日、設計を考え直す時間を取れるか。**
   取れないなら 未来予測は危険。取れるなら最もリターンが大きい。
3. **その場のデモか、公開して遊ばせるか。**
   デモ重視なら 未来予測。公開重視なら 見えない迷路。
4. **問題を作る時間を確保できるか。**
   確保できないなら あと1手は選びにくい。逆に、良い盤面を10問作れる自信があるなら、3案で最も濃い体験になる。
