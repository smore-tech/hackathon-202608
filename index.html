共通ループ

CREATE → SHARE URL → SOLVE → RESULT → RETRY / REMIX

Challenge は URL の fragment（#c=…）に JSON → UTF-8 → Base64URL で入っています。 サーバーもDBも不要で、GitHub Pages のような静的ホスティングだけで動きます。解答はURLに含みません。
